# 🖼️ Image Carousel

A responsive **Image Carousel / Slider** with autoplay, navigation buttons, and dots.

## Features
- Auto-play with pause on hover
- Previous / Next controls
- Dot indicators
- Smooth CSS transitions
- Fully responsive

## How to Run
Open `index.html` in your browser.

## Tech Stack
- HTML5
- CSS3 (Transitions, Flexbox)
- Vanilla JavaScript
